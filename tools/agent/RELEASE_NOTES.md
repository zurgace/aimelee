AI-Melee: play Super Smash Bros. Melee offline against [Phillip](https://github.com/vladfi1/phillip) in melee-pc.

**Windows 10/11 (64-bit):** download `AI-Melee-Windows-x86_64.zip` below and follow [the Windows steps in the README](https://github.com/zurgace/aimelee/tree/claude/eager-planck-jptjp9#windows-10) (also in `README-AI-Melee.txt` inside the zip). You need Python 3.12, your own NTSC-U 1.02 disc image and Phillip's source (Code → Download ZIP).

**Linux:** build from source; see [the README](https://github.com/zurgace/aimelee/tree/claude/eager-planck-jptjp9#ai-melee-play-against-phillip).

No game data is included. The build is not code-signed, so Windows SmartScreen asks once (More info → Run anyway).
