AI-Melee: play Super Smash Bros. Melee on PC against the Phillip AI (built on [melee-pc](https://github.com/999sian/melee-pc), [slippi-ai](https://github.com/vladfi1/slippi-ai) and [phillip](https://github.com/vladfi1/phillip)).

**Windows 10/11 (64-bit):** download `AI-Melee-Windows-x86_64.zip` below, extract it and double-click **AI-Melee.exe**; see [the Windows steps in the README](https://github.com/zurgace/aimelee#install-on-windows-1011), also in `README-AI-Melee.txt` inside the zip. You need Python 3.12, your own NTSC-U 1.02 disc image and Phillip's source (Code → Download ZIP).

**Linux:** build from source; see [the README](https://github.com/zurgace/aimelee#install-on-linux-cachyos).

No game data is included. The build isn't code-signed, so Windows SmartScreen asks once (More info → Run anyway).
